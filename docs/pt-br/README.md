# Documentacao Em Portugues Do Brasil

Comece por [INDICE.md](INDICE.md). Esta pasta contem a visao em portugues da
documentacao atual do Autobook.

Arquivos historicos em `others/` sao preservados como contexto. Alguns arquivos
de arquivo podem manter a redacao original porque nao sao o contrato
operacional atual; o contrato vigente esta nos documentos principais ligados
pelo indice.
