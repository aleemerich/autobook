# Referencias Historicas E Criativas

Esta pasta mistura material ainda util para operacao editorial com documentos
historicos do projeto. Use a classificacao abaixo antes de assumir que um
arquivo descreve o comportamento atual do codigo.

## Referencias Operacionais

| Arquivo | Uso |
| --- | --- |
| `CRAFT.md` | Referencia narrativa usada pela pipeline `foundation`. |
| `ANTI-SLOP.md` | Lista editorial de padroes a evitar. |
| `ANTI-PATTERNS.md` | Antipadroes de escrita e estrutura. |

## Historico Ou Material De Estudo

| Arquivo | Observacao |
| --- | --- |
| `PIPELINE.md` | Desenho antigo; contem referencias obsoletas como `run_editorial.py`. |
| `PROJECT_STUDY.md` | Estudo historico do projeto. |
| `WORKFLOW.md` | Workflow antigo. |
| `program.md` | Material de planejamento/ideia. |
| `cauldron.txt` | Material criativo. |
| `results.tsv` | Registro historico de tentativas. |

Documentos historicos nao devem ser usados como contrato tecnico atual sem
validacao contra codigo e testes.
